# Sem03 - Registro de Notas

## Descripción
Aplicación desarrollada en Kotlin con Jetpack Compose para calcular el promedio ponderado de cuatro cursos.

## Controles utilizados
- Slider
- Switch
- Checkbox
- Button

## Funcionalidades
- Asignación de notas de 0 a 20.
- Cálculo del promedio ponderado.
- Redondeo opcional del promedio final.
- Confirmación de notas mediante Checkbox.
- Observación según el promedio obtenido.
- Cambio de color según el resultado académico.

## Pesos de los cursos
- Fundamentos de Programación: 20%
- Programación Orientada a Objetos: 25%
- Programación en Móviles: 30%
- Base de Datos: 25%

## Caso de prueba
- Fundamentos: 15
- POO: 13
- Móviles: 16
- Base de Datos: 14
- Redondear: ON

Resultado:
- Promedio ponderado: 14.55
- Promedio final: 15
- Observación: APROBADO
